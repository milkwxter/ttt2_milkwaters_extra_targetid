# ttt2_milkwaters_extra_targetid
More target ID info for certain things, with some addon support.

- Weapons now show what ammo box they use
- Ammo boxes tell you their name, if you can pick them up currently, and how to pick them up
- Support for "Stealthy Door Opening": https://steamcommunity.com/sharedfiles/filedetails/?id=2151694266
- Support for "TTT: Players can hide in closets": https://steamcommunity.com/sharedfiles/filedetails/?id=655039219
